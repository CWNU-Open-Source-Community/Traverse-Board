## 已实现

- 活动任务、归档和项目列表复用现有 cursor API 与 TanStack Query 分页。历史页可继续加载，加载失败保留已有结果并可重试；归档可直接阅读，也可用原有版本校验恢复。
- 侧栏按工作区 ID 分组，同名或名称尚未加载时显示 ID 辅助区分。分组不再逐条复制同组数组。
- 搜索明确只过滤已经加载的对应状态标题，不含消息正文；提示是否还有历史页，区分尚未加载、加载失败、没有记录和没有匹配项。
- 任务有 `#/threads/<id>` 地址，新任务和设置也有地址。任务选择由地址决定，刷新列表不会因为所选任务不在前 100 条就切走。浏览器前进、后退与重新连接保留任务身份；首次无地址进入才使用已选任务或首项作为默认值。
- 设置页保留来源任务，新任务继承当前任务项目。设置往返继续使用原有按任务/项目隔离的内存草稿；刷新或退出后草稿持久化仍不在完成范围。
- 多页历史不再每 4 秒全量轮询；持久变更、显式刷新和 Query 的既有重新获取机制继续同步。当前任务仍有独立状态查询。
- 归档空记录不再暗示继续执行；Inspector 文案指向主界面的日常审阅。文件选择弹层的关闭栏在滚动时保持可见。

取舍与限制见 [ADR 0149](adr/0149-cursor-history-and-fragment-task-navigation.md)。
