## 检查中纠正的误判与局限

- 服务启动时会把 `--ui-dir` 载入内存；仅重建前端再刷新仍可能使用旧包。本次先核精确 PID/命令及空闲状态，再重启隔离服务，实际读取 script URL 核新构建。旧中间截图不可冒充最后版本。
- 390 遮罩点击的首次 CLI 超时来自默认点击中心落在侧栏内；实际外部遮罩可关闭，不是侧栏故障。设置按钮早期脚本使用显示字而不是完整可访问名称，已用新快照纠正，不记为产品故障。
- 早期部分测量脚本只 `console.log`，工具未输出其数值；这些日志不作测量证据，后改为 return。Ctrl+加号没有产生可确认的浏览器缩放，本报告不声称做过 125%/150% DPI 测试。
- 模型菜单透明重叠已在关闭动画后复查仍存在，才实施修正；新背景仅在本次 Chromium/生产 UI 验证，原生 WebView2 的兼容性仍待实际覆盖。
- 历史首次乱码、旧审批后不准确文案、旧 Pro 缺少网页终局收据仍保留，禁止回填成成功。不会因本次显示修正改写 Q 或真实工程结论。
