## 最新后续批次：搜索与失败收束

MiMo 交接报告记录了以下实现，代码已纳入本分支：

1. 不可用网页工具提供具体原因及操作者入口。
2. 搜索失败区分 `provider unreachable (network/proxy)` 与 `no usable results`。
3. 生成摘要解析容忍未知扩展字段，继续校验版本、摘要内容和长度；存储层权限边界保持独立。
4. 当前执行段的最旧完整工具轮可收敛为有界收据，并接入 Supervisor 的两个上下文耗尽分支。
5. `FailSupervisorTurn` 在适用的 running 边界收束为 paused，保留新输入继续同一任务的入口；相关测试补齐显式 Resume。

## 2026-09-16 CI 修复中的上下文验收边界

完整 Go 检查暴露了旧测试夹具与当前默认生成式摘要路径不一致的问题。长对话回归现通过独立的摘要模型夹具走默认路径，保留原 24 轮自然语言输入、重开数据库、目标与后续纠正、限制、未完成事项、工具结果 SHA 和不可授权断言；另核对两次摘要的来源指纹与完成收据。它验证摘要接线和证据传递，不验证真实模型的总结质量。

规则回退仍有已确认限制：在 4000 字符、12 条记录的固定边界内，多次自然语言“继续”会挤掉较早纠正，头尾摘录也可能省略目标或工具记录中段。现有历史回读可按原始记录定位证据，但不能据此声称模型一定会主动找回遗漏语义。本批未修改规则摘要选择算法，也未重新进行付费长任务验收。后续应以同一输入序列验证规则改进，并同时保留多项真实纠正和有界淘汰的回归，不能只增加固定保留数量。
