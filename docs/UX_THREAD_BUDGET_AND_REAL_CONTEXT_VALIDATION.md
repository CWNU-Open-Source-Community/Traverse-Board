## 已实施的行为变化

- Supervisor从具备金额存储能力的实际store默认安装服务，Desktop/API/Handoff共享该入口。配置金额上限而缺少服务或有效价格时，调用前明确阻止；无金额上限的旧任务不新加价格要求。
- 普通请求按实际Supervisor AttemptID和模型调用序号绑定金额身份，不再跨Turn碰撞；摘要与旧记录有各自兼容区间。旧已落库预留不被改名，按其真实start/terminal来源核对。
- Run剩余额度扣除累计已结算费用和在途预留，结算不再将已花费金额加回。现有契约仍是Run级预算；模型切换产生后继Run时保留旧Run账，不把新Run误说成Thread全生命周期总额度。
- 已收到的用量独立于正文/工具是否被接受；格式错误、停止、响应保存失败仍能记账。未知用量保留保守估算，不能当免费。停止后只接受精确原请求的计账，不复活执行或提交晚到正文。
- 价格按预留时的不可变快照结算；执行中更换当前价或快照到期不会改写原请求价格。
- 输入估计包含实际工具schema和现有图片窗口估计，修掉工具只按固定128字节估计的遗漏。这仍是本地规划估计，不是供应商实际账单或通用视觉计费上界。
