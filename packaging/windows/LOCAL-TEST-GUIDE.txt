Traverse Board · 针路簿 Windows 本地试用说明
==========================

推荐入口
--------
直接双击 TraverseBoard.exe。这是面向用户的完整入口，不需要解压 ZIP、命令脚本、
启动参数或另行启动后端。当前源码和新 Release 都不再提供 Start 命令脚本；开发者
也直接运行 build\desktop\TraverseBoard.exe。

默认入口启用首次编码所需的安全控制面与沙箱 adapter，不启用完全访问、Debug
最大权限、完整 CDP、后台唤醒/定时 Worker 或 Agent 持久终端。若只需要查看，
可从 PowerShell 运行 `./TraverseBoard.exe --safe-view`，该入口不创建 control token。

首次接入真实模型
----------------
1. 首次双击 EXE 后，按向导选择语言与 Provider。
2. 在向导“系统凭证”中为 mimo、deepseek 或 anthropic 输入 API 凭证并保存。
   凭证由 Windows Credential Manager 保管，不写入 SQLite、日志或事件流。
3. 如果界面提示需要重启，请关闭针路簿，然后再次双击 EXE。
4. 依次点击 Provider 的“连接诊断”和“Harness 验证”。Harness 验证会发起
   最多两次真实、受限的模型请求，但不会执行 Shell、文件、浏览器或工具动作。
5. 选择工作区、核对 Go 返回的后端 readiness 与工作区摘要，然后显式确认信任。
   向导会原子创建 Standard Code Run；选择目录本身不会自动信任或修改文件。

真实对话
--------
1. 在首次向导完成后点击“开始编码”，或从首页使用同名唯一入口。
2. 在底部输入区输入消息并发送。
3. 针路簿会创建或复用该 Run 的 Session，持久化用户消息，执行一个有界
   Supervisor step，并把真实 Provider 回复写回会话。刷新或重启后可继续读取。

语言
----
默认语言为中文。进入“设置与账户 > 个人 > 常规 > 语言”可一键切换中文和
English；选择保存在本机界面存储中。

数据与排障
----------
默认数据目录：%USERPROFILE%\.cyberagent-workbench
“便携”仅表示程序文件免安装；默认数据不会跟随解压目录。重新下载或换目录解压
仍会使用同一用户数据目录。只有显式设置 CYBERAGENT_HOME 才会使用隔离测试目录。
不要把 API key、cyberagent.db 或凭证截图提交到 Issue。
若启动失败，请保留本地数据，记录错误代码，并检查 Microsoft Edge WebView2
Runtime 是否已安装或更新。


Traverse Board Windows Local Test Guide
==============================

Recommended entry point
-----------------------
Double-click TraverseBoard.exe directly. It is the complete user-facing entry and requires no
ZIP extraction, command script, startup flag, or separately started backend. Current source and
new releases provide no Start command script; developers also run
build\desktop\TraverseBoard.exe directly.

The default enables the safe control plane and sandbox adapter needed for first-time
coding. It does not enable danger-full-access, maximum Debug, Full CDP, background
wake/scheduled workers, or an Agent-controlled persistent terminal. For read-only use,
run `./TraverseBoard.exe --safe-view` from PowerShell; Safe View creates no control token.

Connect a real model
--------------------
1. On the first direct launch, choose a language and Provider in the setup wizard.
2. Store an API credential for mimo, deepseek, or anthropic under System credentials.
   Windows Credential Manager owns the secret; SQLite, logs, and events do not.
3. Restart Traverse Board by double-clicking the EXE if the interface requests it.
4. Run Provider diagnostics, then Harness qualification. Qualification performs at
   most two bounded real model calls and executes no shell, file, browser, or tool action.
5. Choose a Workspace, review Go-owned backend readiness and the Workspace digest,
   then confirm trust explicitly. The wizard atomically creates a Standard Code Run;
   choosing a directory alone neither trusts nor modifies it.

Real chat
---------
1. Choose Start coding when the wizard completes, or use the single matching home entry.
2. Send a message from the composer.
3. Traverse Board creates or reuses the Run Session, persists the user message, runs one bounded
   Supervisor step, and stores the real Provider response. Refresh and restart recovery
   use the same durable conversation.

Language
--------
Chinese is the default. Use Settings and account > Personal > General > Language to
switch between Chinese and English. The choice is stored locally for the interface.

Data and diagnostics
--------------------
Default data directory: %USERPROFILE%\.cyberagent-workbench
Portable means install-free application files; data does not follow the extracted directory.
Downloading or extracting another ZIP reuses the same user data home. Only an explicit
CYBERAGENT_HOME selects an isolated test directory.
Never attach API keys, cyberagent.db, or credential screenshots to an issue.
For startup failures, preserve local data, record the stable error code, and verify that
Microsoft Edge WebView2 Runtime is installed and current.
