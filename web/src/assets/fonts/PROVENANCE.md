# HarmonyOS Sans SC asset provenance

Traverse Board uses four HarmonyOS Sans SC weights for its Simplified Chinese interface. The font metadata identifies Huawei Device Co., Ltd. and Hanyi Fonts, version 2.400.

The applicable license text is copied from the official OpenHarmony [`global_system_resources/LICENSE_Fonts`](https://github.com/openharmony/global_system_resources/blob/master/LICENSE_Fonts) file and is shipped in `web/public/licenses/HarmonyOS-Sans.txt`. The repository README, General settings page and `web/public/THIRD-PARTY-NOTICES.txt` provide source, in-product and distribution notices.
